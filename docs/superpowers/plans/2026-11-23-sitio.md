# Sitio club-vanta.com: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** publicar `club-vanta.com`: una home renderizada en el edge con el próximo alter y los pasados, y `/reglas` estática, idénticas a los mocks aprobados, con toda la infra de Cloudflare en OpenTofu.

**Architecture:** Astro 6 con `@astrojs/cloudflare` (v13) sobre un Worker. La home (`output` por defecto `static`, la home con `export const prerender = false`) pide `GET /public/alters` al backend, la guarda en la Cache API de Workers (`caches.default`) 15 minutos y, si el backend falla o tarda, usa la última copia que siga en caché. La lógica (elegir el próximo, formatear fechas, armar la cinta, decidir de dónde salen los datos) vive en funciones puras con Vitest. Playwright prueba la página real contra un backend falso. OpenTofu declara Worker y dominios; GitHub Actions sube el código con `wrangler deploy`.

**Tech Stack:** Astro 6, `@astrojs/cloudflare` 13, Wrangler, TypeScript estricto, Vitest, Playwright + `@axe-core/playwright`, ESLint con `eslint-plugin-astro` (incluye reglas `jsx-a11y`), Prettier con `prettier-plugin-astro`, `openapi-typescript`, OpenTofu con `cloudflare/cloudflare ~> 5`, devenv + direnv.

**Spec:** `docs/superpowers/specs/2026-11-23-club-vanta-web-design.md`. Leer también `docs/decisiones.md` (sección "Plan de implementación"), `docs/heredado-de-velvet.md`, `docs/contexto.md` y `docs/reglas-v0.2.md`.

**Depende de:** `docs/superpowers/plans/2026-11-23-backend-endpoint-publico.md`. Hasta que ese PR esté en `main` del backend, los tipos se generan desde `../alter-tracker-backend/openapi.json` de la rama `feat/public-alters` (Task 3).

## Global Constraints

- **Mocks como fuente de verdad visual:** `docs/mocks/home.html`, `docs/mocks/reglas.html`, `docs/mocks/mobile.html`. El texto visible se copia literal de ahí. Los elementos `.pin` (etiquetas amarillas) y `.mockup-header` son del visor de mocks: no van al sitio.
- **Tokens** (únicos valores permitidos; todo lo demás los referencia): `--ink: #0d0d0d`, `--paper: #f1eee6`, `--red: #e2574c`, `--mute: #a9a49a`, `--ink-2: #151515` (fondo del archivo en el mock). Espaciado `4 8 12 16 24 32 48 64 96` px. Radio `0`, salvo el carnet: `18px` escritorio, `14px` mobile. Curva `--ease-out: cubic-bezier(0.16, 1, 0.3, 1)`.
- **Tipografías (Google Fonts):** League Gothic 400; Sofia Sans Extra Condensed 800 y 900; Sofia Sans 400 y 700. Ninguna otra. Nada de Inter, Roboto, Georgia ni monoespaciadas.
- **Movimiento:** solo la cinta se mueve sola, y se frena con `prefers-reduced-motion: reduce`. Transiciones solo de `transform`, `opacity` y `filter`, siempre con `var(--ease-out)`.
- **Privacidad:** nunca se muestra dirección, coordenadas ni nada de asistentes. El sitio dice solo "San Telmo". Los datos solo traen lo que define `PublicAlter`.
- **Copy** en rioplatense con voseo, voz de `docs/contexto.md`. Sin em dashes ni abreviaturas latinas en copy, código, comentarios ni commits.
- **Fechas:** siempre con `timeZone: "America/Argentina/Buenos_Aires"`. Tests con `TZ=UTC`.
- **Infra:** todo lo de Cloudflare en `infra/` con OpenTofu (`tofu`, nunca `terraform`). Nada a mano en la UI.
- **HTML:** cada página empieza con `<meta charset="utf-8">`; `lang="es-AR"`.
- **Corte responsive:** layout mobile por debajo de `900px`, escritorio desde `900px`. Diseñado a 375 y 1280; revisar también a 768, 1024 y 1440 sin scroll horizontal.
- Antes de decir "listo" en cualquier task: `npm run check`, `npm run build`, `npm run test:run` y, desde la Task 5, `npm run test:e2e`.

## Review Focus

- **Backend caído (deploy, reinicio) con una copia vieja en caché que tiene un "próximo" que ya pasó:** la home lo muestra como pasado y queda "sin fecha". Test en Task 3 (`selectAlters` con `now` después del margen) y Task 5 (escenario `past-next`).
- **Alter del jueves a las 20.30 en Buenos Aires (23.30 UTC) o pasada la medianoche UTC:** se ve "JUE", nunca "VIE". Test en Task 3.
- **Backend lento:** la página no espera más de 2.5 s y renderiza con la copia o sin fecha. Test en Task 4 (timeout) y Task 5 (escenario `slow`).
- **Respuesta con forma inesperada** (HTML de error de Cloudflare con 200, JSON sin `alters`, alter sin `date`): se trata como falla y no pisa la copia buena en caché. Test en Task 4.
- **Portada que no carga** (`cover_url` null o mazmocdn caído): no queda un hueco roto; el tile muestra el nombre sobre negro y el `alt` describe el flyer. Test en Task 6 (fixture con `cover_url: null`).

### Task 4: Datos con caché y redirección de www

**Files:**
- Create: `src/lib/get-alters.ts`, `src/lib/snapshot-cache.ts`, `src/lib/www-redirect.ts`, `src/middleware.ts`

**Interfaces:**
- Consumes: `PublicAlter` (Task 3).
- Produces, en `src/lib/get-alters.ts`:

```ts
export interface Snapshot { fetchedAt: string; alters: PublicAlter[] } // fetchedAt en ISO
export interface SnapshotStore {
  get(): Promise<Snapshot | null>;
  put(snapshot: Snapshot): Promise<void>;
}
export interface GetAltersDeps {
  fetchImpl: typeof fetch;
  store: SnapshotStore;
  apiUrl: string;          // base, sin barra final
  freshSeconds: number;    // 900 en producción, 0 en e2e
  timeoutMs: number;       // 2500
  now: Date;
}
export type AltersSource = "fresh-cache" | "backend" | "stale-cache" | "none";
export async function getAlters(deps: GetAltersDeps): Promise<{ alters: PublicAlter[]; source: AltersSource }>;
```

  `src/lib/snapshot-cache.ts` exporta `function cacheSnapshotStore(cache: Cache): SnapshotStore`, que guarda la copia en `caches.default` bajo la URL sintética `https://club-vanta.com/__alters-snapshot/v1` con `Cache-Control: max-age=604800` (una semana como respaldo; la frescura la decide `fetchedAt`, no el TTL).

  Orden: si hay copia con menos de `freshSeconds`, se usa sin llamar al backend; si no, `GET {apiUrl}/public/alters` con `AbortSignal.timeout(timeoutMs)`; si responde 200 con forma válida, se escribe la copia y se devuelve; si falla, se usa la copia vieja si existe; si no, `{ alters: [], source: "none" }`. Nunca lanza.
- Produces: `function wwwRedirect(url: URL): string | null` -> `"https://club-vanta.com/reglas?x=1"` para `https://www.club-vanta.com/reglas?x=1`, `null` para cualquier otro host. `src/middleware.ts` responde 301 con eso.

  - copia vieja y backend OK -> `source: "backend"`, la copia se actualiza con `fetchedAt = now`.
  - sin copia y backend OK -> `source: "backend"`.
  - copia vieja y backend 503 -> `source: "stale-cache"` con los alters de la copia.
  - copia vieja y backend que tarda más que `timeoutMs` (promesa que respeta `signal`) -> `source: "stale-cache"`, y el test termina en menos de `timeoutMs + 200` ms.
